Autonomous Triple-Stage Decision Architecture
Algorithm from ebs_stale_snapshosts.py • Click any step to filter
Stage 1: Discovery
Inventory Self Snapshots
Queries AWS EC2 for snapshots owned by account (OwnerIds=['self']).
ec2:DescribeSnapshots
Stage 2: Instance Context
Active EC2 Discovery
Finds all running EC2 instance IDs. Creates lookup index for attachment cross-check.
ec2:DescribeInstances
Stage 3: Volume Cross-Ref
Volume Attachment Audit
Checks if source volume exists. Catches InvalidVolume.NotFound & unattached states.
ec2:DescribeVolumes
Stage 4: Execution
Purge or Preserve
Safely retains active production data; safely purges orphaned zombies with zero manual effort.
ec2:DeleteSnapshot
